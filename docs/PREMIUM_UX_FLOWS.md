# NISAA CARE Premium UX Flow

## 1. First launch

Brand mark → warm visual hero → purpose → language → privacy promise → profile → health context → marriage context → cycle baseline → notification preference → completion.

Rules:
- one decision per step
- progress is always visible
- no unnecessary account creation before local value is established
- language selection happens early
- privacy explanation appears before sensitive data collection
- Arabic uses RTL throughout the experience

## 2. Woman home

Today → personal greeting → visual wellness hero → cycle status → confidence → primary logging action → fertility/education shortcuts → wellbeing → faith → quotation → privacy/offline status.

The visual hero is intentionally decorative; cycle calculations and safety information remain the primary information hierarchy.

## 3. Cycle flow

Calendar → selected day → period start/end → flow → symptoms → notes → save → deterministic recalculation → history.

No calendar estimate is presented as guaranteed contraception.

## 4. Fertility flow

Observed history → algorithm version → estimate → confidence → explanation → educational context → safety disclaimer.

Insufficient data is a first-class state rather than hidden uncertainty.

## 5. Faith flow

Faith hero → topic categories → source/provenance → selected content → translation switcher → scholarly-context note where needed.

Religious content must never be generated merely to fill visual space.

## 6. Marriage flow

Marriage hero → relationship state → invite/accept → explicit permissions → support requests → shared information → revoke.

The wife controls sensitive sharing. A husband receives only information explicitly permitted.

## 7. Husband flow

Family/support hero → relationship state → permitted information → support actions → husband education → marriage controls.

The husband experience is intentionally not a copy of the woman's health dashboard.

## 8. States

Every major screen should support:
- first-use/empty
- loading
- populated
- offline
- error/retry
- pending review
- restricted/private
- success
- insufficient-data/low-confidence

## 9. Visual language

Warm cream surfaces, walnut/ink typography, muted rose as the primary action color, terracotta and sage as supporting semantic accents, antique gold for heritage/context, restrained geometric decoration, vector illustrations, generous spacing, 48dp minimum interactive targets and strong RTL support.

Avoid:
- blue-heavy generic medical dashboards
- excessive gradients
- emoji as interface icons
- decorative animation that distracts from health decisions
- stock imagery without verified redistribution rights
- inaccessible text over photography
